# Инструкция: назначение темы вопросу

Ты получаешь вопросы, которые были размечены как смешанная секция «HTML/CSS». Назначь каждому ровно одну каноническую тему: `html` или `css`.

Вход — JSON-файл батча, поле `questions`. Выход — строго JSON без markdown-обёртки:

```json
{
  "batchId": "<batchId из входа>",
  "assignments": [{ "id": "<id вопроса>", "topic": "html" }]
}
```

## Правила

1. `html` — если вопрос про разметку, элементы, атрибуты, семантику, формы, валидность документа, доступность разметки.
2. `css` — если вопрос про стили, селекторы, каскад, специфичность, box model, layout, адаптив, анимации, шрифты, цвета.
3. Если вопрос касается и того и другого — выбери тему по главному предмету вопроса.
4. Один вопрос — ровно одно назначение; id копируй без изменений.
